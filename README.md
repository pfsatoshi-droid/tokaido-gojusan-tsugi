# ぷっぷーとぷーぷの東海道五十三次

二匹と一緒に日本橋から京都・三条大橋まで旅する、レスポンシブな Web アプリです。

## 開発

Node.js 20.19+ または 22.12+ が必要です（クラウド環境では Node.js 24 で確認）。

```sh
npm ci
npm run dev
```

## 検証

```sh
npm run build
npm test
```

ブラウザテストは、このクラウド環境の `/usr/bin/chromium` を利用します。別の環境では `playwright.config.js` の executablePath を変更してください。

## 機能

- 日本橋・53宿・三条大橋の55地点を表示
- 地域と宿場名による絞り込み
- OpenStreetMap の道路地図、55地点の宿場ピン、拡大・縮小、訪問済み表示
- 現在地表示（利用時のみ位置情報の許可を要求、アプリには保存しません）
- 日本橋から三条大橋まで全54区間の徒歩ルートを地図内に常時表示（選択中の区間を強調）
- 補助として Google マップの徒歩経路リンク
- 宿場の紹介、前後の宿場への移動
- 訪問記録、進捗表示、旅のメモ
- localStorage によるブラウザ単位の保存（サーバー同期はありません）

イラストは旅の雰囲気を表すオリジナル SVG で、各宿場の実景ではありません。人物のデザインは本アプリ用の仮デザインです。フォントは Google Fonts を利用し、取得できない環境では端末のフォントに切り替わります。

## マップ

上部の「マップ」または宿場一覧の表示切り替えから開けます。宿場を選ぶと道路が見える縮尺まで拡大します。「宿場の紹介」で紹介画面を、「Google マップで徒歩経路」で外部の経路検索を開きます。地図は Leaflet と OpenStreetMap の標準タイルを使用し、表示中の範囲のみ取得します。地図の一括ダウンロードやオフラインキャッシュは行いません。

宿場ピンは宿場付近の概略位置です。徒歩経路を開いた先で出発地と目的地を確認してください。旧東海道の厳密な道筋は収録していません。

道路地図には `tile.openstreetmap.org`、徒歩経路には `www.google.com` への通信が必要です。現在地は HTTPS 上で許可された場合に表示します。地図や位置情報を利用できない場合は画面に案内を表示します。クラウド環境での操作テスト7件は成功しました。経路描画テストは固定のサービス応答を使用しており、ネットワーク制限で実タイル・実経路取得と公開サイトの表示は未確認です。

徒歩ルートは `routing.openstreetmap.de` の FOSSGIS routed-foot バックエンドで取得します。OSRM API の URL は `/routed-foot/route/v1/driving/` ですが、利用するバックエンドは徒歩用です。全55地点を1回のリクエストで経由し、全54区間をまとめて取得します。青い全ルートは宿場選択・検索・地域絞り込みで消えず、選択区間だけ橙色で強調します。取得結果はページ内メモリで再利用し、宿場変更のたびに再検索しません。現在地はルートサービスに送信せず、宿場座標だけを送信します。失敗時には架空の直線を表示せず再読み込みを案内します。全区間の旧東海道の検証済みルートではありません。

## GitHub Pages で開く

公開用ファイルは `docs/` に含まれています。GitHub の Settings → Pages で Source を「Deploy from a branch」、Branch を `main`、Folder を `/docs` にして Save を押すと公開できます。

公開先: https://pfsatoshi-droid.github.io/tokaido-gojusan-tsugi/

アプリを更新した場合は `npm run build:pages` で公開用ファイルを再生成し、`docs/` もコミットしてください。公開設定の有効化とデプロイ完了が必要です。

## 宿泊地ごとの旅程プランナー

「マップ」内の「何泊で、どこまで歩こう？」で、地図を押す・宿場を選ぶ・ホテル名や住所を検索する、のいずれかで宿泊地を登録します。1日目は日本橋から1泊目、2日目は1泊目から2泊目という順で徒歩距離と所要時間を表示します。最大20泊まで保存でき、名前変更・順序変更・削除・ピンのドラッグに対応します。

計画はブラウザのlocalStorageに保存します。距離と時間はFOSSGISの徒歩経路の目安で、休憩や観光は含まず、旧東海道や既存の青線に沿う保証はありません。経路に宿泊地の座標を送信します。場所検索はユーザーの検索操作時だけNominatimへ送信し、自動補完は行いません。検索できない場合も地図から登録できます。検索・経路サービスへの実接続は環境の通信制限により未確認です。固定応答を用いた保存・日別計算・並べ替え・エラー表示を含むブラウザテスト10件が成功しています。

### 25kmプランと縦の旅程図

初回は全線の徒歩ルートを取得した後、道路に沿った累計約25kmごとの目安ピンと、京都の到着点を自動作成します。保存済み計画は自動で置き換えず、「1日約25kmのプランを作る」から置き換えを選べます。ピンは宿泊施設の確認済み位置ではありません。最終日は25km未満になることがあり、各日の再検索により実際の距離も変わり得ます。

縦の旅程図は日本橋→各宿泊地点→京都の順に表示し、各日の徒歩距離・時間・累計距離を示します。表示間隔は縮尺ではありません。全線取得に失敗した場合は自動プランを作らず、手動で地点を追加できます。最大60地点に対応します。ブラウザテスト11件が成功しています（経路サービスは固定応答で検証）。

### 宿泊地点の周辺ホテル検索

宿泊ピン、縦の旅程図の地点、または日別カードの「近くのホテルを探す」を押すと、周辺ホテル検索の案内が開きます。リンクは地点の緯度経度を指定した Google マップのホテル・旅館検索です。外部サイトで開き、料金・空室・予約は検索先で確認します。

周辺ホテル検索はOverpass APIから半径3kmの宿泊施設を取得し、直線距離順に表示します。「この宿を宿泊地にする」でピンを施設へ移し日別距離を再計算します。未登録施設・空室・営業状況は取得できません。失敗時は地点を中心にしたGoogle マップ検索を利用できます。検証は固定応答による検索条件・範囲外除外・宿泊地点変更のブラウザテストで行っています。
